# Every way to join a word

[← back to the table of contents](README.md) · [← back to the main README](../README.md)

A one-page sheet for practice. When you don't know a word's one-stroke outline, or it has none,
build it from pieces you already know and hold the join key (`+`) on every stroke after the first.
Every word of two syllables or more in the dictionary can be reached at least one of these ways
(98–99% in every frequency band), most of them several. The examples are real entries from the
current build. The chapters behind each rule: [suffixes](suffixes.md), [prefixes](prefixes.md),
[syllables & folding](syllables.md).

## 1. A word you know, then its ending

Stroke the stem the way you always do, then the ending's stroke.

| Ending | Stroke | Example |
|---|---|---|
| -s | `+-S` / `+-Z` | *looks* `HRAOBG/+-S`, *dogs* `TKOG/+-Z` (`-Z` when it sounds like z) |
| -ed | `+-D` | *played* `PHRAEU/+-D` |
| -ing | `+-G` | *walking* `WAUBG/+-G` |
| -er, -or | `+-R` | *sailor* `SAEUL/+-R` |
| -est | `+-FT` | *fastest* `TPAS/+T-FT` |
| -ly | `+-L` | *kindly* `KAOEUPBD/+-L` |
| -y | `+AOE` | *rainy* `RAEUPB/+AOE` |
| -en | `+-PB` | *golden* `TKPWOELD/+-PB` |
| -ness | `+-PBS` | *darkness* `TKARBG/+-PBS` |
| -ment | `+-PLT` | *payment* `PAEU/+-PLT` |
| -able, -ible | `+-BL` | *readable* `RAOED/+-BL`, *sensible* `SEPBS/+-BL` |
| -ful | `+-FL` | *careful* `KAEUR/+-FL` |
| -less | `+-LS` | *careless* `KAER/+-LS` |
| -ship | `+SH-P` | *friendship* `TPREPBD/+SH-P` |
| -hood | `+HAOD` | *childhood* `AOEULD/+HAOD` |
| -ward | `+WORD` | *homeward* `HOEPL/+WORD` |
| -tion | `+-GS` | *nation* `TPHAEU/+-GS` |
| -ation | `+AEUGS` | *information* `EUPB/+TPORPL/+AEUGS` |
| -ish | `+-RB` | *childish* `KHAOEULD/+-RB` |
| -ist | `+EUFT` | *artist* `ART/+EUFT` |
| -ism | `+EUZ/+-PL` | *tourism* `TUR/+EUZ/+-PL` |
| -ize | `+AOEUZ` | *modernize* `PHOD/+-RPB/+AOEUZ` |
| -ous | `+US` | *famous* `TPAEUPL/+US` |
| -ive | `+-F` | *active* `ABGT/+-F` |
| -tive | `+T-F` | *positive* `PO/+STKPWU/+T-F` |
| -ic | `+-BG` | *heroic* `HEU/+ROE/+-BG` |
| -ical | `+-BG/+UL` | *chemical* `KHEPL/+-BG/+UL` |
| -al | `+UL` | *emotional* `E/+PHOEGS/+UL` |
| -age | `+-PBLG` | *package* `PABG/+-PBLG` |
| -ity | `+U/+TEU` | *humidity* `HAOUPLD/+U/+TEU` |
| -cy | `+U/+SEU` | *legacy* `HREG/+U/+SEU` |
| -ify | `+U/+TPAOEU` | *identify* `AOEU/+TKEPBT/+U/+TPAOEU` |
| -ary, -ery, -ory | `+-R/+AOE` | *dictionary* `TKEUBG/+-GS/+-R/+AOE` |
| -logy | `+OL/+SKWREU` | *biology* `PWAOEU/+OE/+OL/+SKWREU` |
| -some | `+-FPL` | *awesome* `AU/+-FPL` |
| -let | `+-LT` | *booklet* `PWAOBG/+-LT` |
| -th | `+*T` | read as "th" after any stroke by the fallback (no entries yet) |
| -ent | `+-PBT` | *different* `TK-FR/+-PBT` |
| -ance, -ence | `+UPBS` | *presence* `PREZ/+UPBS` |
| 's | `+-PBTS` | read as "'s" after any word by the fallback (no entries) |

Endings stack: *needlessly* is *need* `+-LS` `+-L`. A word that is two words is the two words:
*myself* `PHAOEU/+SEFL`, *outside* `OUT/+SAOEUD`.

## 2. A prefix, then a word you know

Stroke the prefix on its own, then the word with the join key held.

| Prefix | Stroke | Example |
|---|---|---|
| un- | `UPB` | *unclear* `UPB/+KHRAOER` |
| re- | `RE` | *rebuild* `RE/+PWHR` |
| de- | `TKE` | *decode* `TKE/+KOED` |
| pre- | `PRE` | *prefix* `PRE/+TPEUBGS` |
| dis-, mis- | *dis*, *mis* as words | *dislike* |
| in- | `EUPB` | *incorrect* `EUPB/+KREBGT` |
| im- | `EUPL` | *impossible* `EUPL/+POS/+-BL` |
| en- | `EPB` | *enjoy* `EPB/+SKWROEU` |
| co- | `KOE` | *coexist* `KOE/+UG/+STKPWEUFT` |
| non- | `TPHOPB` | *nonstop* `TPHOPB/+STOP` |
| sub- | `SUB` | *subway* `SUB/+WAEU` |
| trans- | `TRAPBS` | *transplant* `TRAPBS/+PHRAPBLT` |
| inter- | `EUPB/+TER` | *interstate* `EUPB/+TER/+STAET` |
| anti- | `APB/+TEU` | *antibody* `APB/+TEU/+PWA/+TKEU` |
| semi- | `SEPL/+EU` | *semifinal* `SEPL/+EU/+TPAOEU/+-PBL` |
| over-, under- | *over*, *under* as words | *overcome* `AUFR/+KUPL` |

## 3. Syllable by syllable

When nothing above fits, say the word and stroke each syllable as you hear it.

- **One syllable, one stroke**, with its vowel: *table* `TAEU/+PWUL`, *machete* `PHU/+SHE/+TAOE`.
- **A weak last syllable drops its vowel**, exactly like a suffix: *table* `TAEU/+-BL`,
  *lemon* `HRE/+PH-PB`, *profitable* `PRAF/+U/+TU/+-BL`.
- **A weak vowel you do stroke is `U`** (a short i is `EU`), whatever letter spells it.
- **Split where you hear the break**: *lem-on* `HREPL/+UPB` and *le-mon* `HRE/+PHUPB` both work.
- **A weak last syllable that fits on the stroke before it can fold onto it**: *sensible*
  `SEPB/+SU/+-BL` or `SEPB/+SUBL`.

## 4. Or the short form

Most long words also have a one-stroke short form (see [how short](brevity.md)): *profitable*
`PROFBLT`, *machete* `PHEFPT`. Learn those for the words you type often. The joins above are
there for every other word.
