# lyk documentation

**The documentation is on the site**: <https://noahlyk.github.io/lyk-steno-theory/>. Lessons teach
typing; the **Reference** (`#/ref`) holds every rule, table and mechanism, searchable. Source: JSON
under [`site/reference/`](../site/reference) and [`site/lessons/`](../site/lessons) (see
[`site/README.md`](../site/README.md)). Docs outrank code: a change to `rules/*.toml` or `src/*.rs`
that changes what a word strokes as lands with the Reference page edit in the same commit.

This folder is the maintainers' record, not learning material:

- [`decisions.md`](decisions.md): why changes landed as they did. Its links to the old chapter
  files now point at the Reference pages below.
- [`roadmap.md`](roadmap.md): a working plan.
